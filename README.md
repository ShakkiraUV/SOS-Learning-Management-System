# 🎓 School of Skills – Learning Management System

A Python-based management system developed using **Object-Oriented Programming (OOP)** and **Streamlit**.

The application provides an interactive interface to manage courses, employees, students, and student-related activities.

## ✨ Features

- 📚 Course Management
  - View courses
  - Search courses by name
  - Search courses by category
  - Display course details

- 👨‍💼 Employee Management
  - View employees
  - Filter employees by department
  - Manage employee details
  - Track employee leave
  - Update phone number and salary

- 🎓 Student Management
  - View student details
  - Filter students by status
  - Track fee payment
  - Track admission type
  - Track placement
  - Manage student leave

- 📊 Activities Dashboard
  - Total students
  - Passed students
  - Dropped students
  - Fee-paid / unpaid students
  - New admissions
  - Placed students

- 🏫 SOS Details
  - Institution information
  - Location
  - Starting year
  - Founder and contact details

## 🛠️ Technologies Used

## 📁 Project Structure

```text
School-of-Skills/
│
├── pro.py
├── stream.py
└── README.md
```

### `pro.py`

Contains the main Python logic, including the `SOS`, `Courses`, `Employees`, `Student`, and `SOSActivities` classes, along with objects, methods, and data management.

### `stream.py`

Contains the Streamlit interface used to interact with the management system through different pages such as Dashboard, Courses, Employees, Students, Activities, and SOS Details.
